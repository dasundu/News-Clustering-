# Lightweight API deployment (e.g. Render free tier) serving /clusters,
# /articles, /stats — and, now, /search.
#
# /search used to be impossible here: embedding the incoming query needed the
# local model in-process, i.e. torch + sentence-transformers (~1.2GB). With
# EMBEDDING_PROVIDER=gemini the query is embedded over HTTP instead, so this
# set only gains `requests` and `numpy` (~30MB) and the search route works on
# the same small host as everything else. That was the main reason for
# switching providers at all.
#
# Still deliberately excludes torch, sentence-transformers, hdbscan,
# scikit-learn, trafilatura and the scraping libraries — the scrape/embed/
# cluster loop runs elsewhere against the same database.
#
# Run with PIPELINE_ENABLED=false so every write route returns a clean 503.
# Set SEARCH_ENABLED=false as well only if you do not want this host making
# Gemini API calls.
fastapi
uvicorn[standard]
psycopg2-binary
pydantic
python-dotenv
requests        # Gemini embedding calls from /search
numpy           # vector handling in embedding_provider / searcher
